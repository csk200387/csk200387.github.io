01. 도구와 운영자

02. 접근하는 정보

  • 계정 식별 정보: Google 로그인에서 승인한 이메일 주소와 기본 프로필 정보입니다.
  • Google Tasks 정보: 할 일 목록, 할 일 제목, 메모, 기한, 완료 상태 및 API가 반환하는 관련 식별자·메타데이터입니다.
  • 인증 정보: 승인된 Google API에 접근하기 위한 OAuth 액세스 토큰과 갱신 토큰입니다.

사용하는 Tasks API 권한은 https://www.googleapis.com/auth/tasks입니다. Google 계정 비밀번호를 도구가 직접 입력받거나 저장하지 않습니다.

03. 이용 목적

정보는 계정 소유자가 요청한 할 일 조회, 등록, 수정, 완료 처리 및 그 결과 설명에 이용합니다. 계정 식별 정보는 연결할 Google 계정을 확인하는 데 사용하고, 인증 정보는 승인된 API 요청과 인증 자동 갱신에 사용합니다.

Google 사용자 데이터를 광고, 판매 또는 신용평가 목적으로 이용하지 않습니다. 이 도구 자체가 Google 사용자 데이터를 이용해 범용 AI 모델을 학습시키거나 미세 조정하지 않습니다.

04. 저장과 보관

gws의 OAuth 인증 정보는 사용자 기기에 암호화하여 저장하며, 암호화 키는 현재 구성에서 운영체제 키링으로 관리합니다. 인증된 API 요청에 사용하는 단기 액세스 토큰은 로컬 캐시에도 저장될 수 있습니다.

조회된 할 일과 작업 결과는 Hermes의 대화 기록, 도구 실행 기록 또는 사용자가 요청한 로컬 문서에 포함될 수 있습니다. 기록의 보관 기간은 해당 도구의 설정과 사용자의 삭제 시점에 따릅니다. 접근 권한 철회만으로 이미 저장된 기록이 삭제되지는 않습니다.

이 안내 웹사이트는 인증 정보나 할 일 데이터를 저장하는 서버로 사용하지 않습니다.

05. 외부 전송과 공유

API 요청은 Google로 전송됩니다. Hermes가 요청을 이해하고 결과를 설명하는 과정에서는 요청 처리에 필요한 할 일 정보와 대화 내용이 사용자가 선택한 AI 모델 제공자에게 전송될 수 있습니다. 실제 전송 대상은 당시 사용 중인 Hermes 모델·제공자 설정에 따릅니다.

이 도구가 Google OAuth 인증 정보를 AI 프롬프트에 포함하도록 설계하지는 않습니다. Google 및 AI 모델 제공자가 처리하는 데이터에는 각 제공자의 개인정보처리방침과 계정 설정이 적용됩니다.

이 웹사이트는 분석 스크립트, 광고, 외부 폰트 또는 로그인 기능을 포함하지 않습니다. 웹사이트 호스팅 제공자인 GitHub Pages는 접속 과정의 IP 주소 등 기술 정보를 자체 정책에 따라 처리할 수 있습니다. GitHub 개인정보처리방침에서 확인하실 수 있습니다.

06. 연결 해제와 삭제

Google 계정의 서드 파티 연결 관리에서 gwsForOC에 부여한 권한을 철회할 수 있습니다. 철회 후에는 다시 승인하기 전까지 해당 연결을 통한 Google API 접근을 사용할 수 없습니다.

로컬 인증 정보는 gws의 로그아웃 기능으로 제거할 수 있습니다. 대화 및 실행 기록, 내보낸 문서는 Hermes와 각 저장 위치에서 별도로 삭제해야 합니다. Google Tasks에 이미 등록된 할 일은 Google Tasks에서 직접 삭제하거나, 연결이 유효한 동안 에이전트에 삭제를 요청할 수 있습니다.
